# Artificial Neural Networks (ANN)

## What is an ANN?

An **Artificial Neural Network (ANN)** — also called a **Multi-Layer Perceptron (MLP)** — is the most fundamental deep learning architecture. It consists of fully connected layers of neurons that learn to map inputs to outputs.

ANNs work best for:
- Tabular/structured data
- Simple pattern recognition
- Classification and regression tasks

---

## Architecture Deep Dive

```
Input Layer    Hidden Layer 1   Hidden Layer 2   Output Layer
─────────────────────────────────────────────────────────────
   x₁ ──┐
         ├──→ [64 neurons] ──→ [32 neurons] ──→ [1 neuron]
   x₂ ──┤    (relu)            (relu)           (sigmoid)
         │
   x₃ ──┘

Each connection has a learnable WEIGHT.
Each neuron has a learnable BIAS.
Total parameters = (n_inputs × 64 + 64) + (64 × 32 + 32) + (32 × 1 + 1)
```

### Activation Functions Comparison

| Function     | Range      | Equation               | When to Use              |
| ------------ | ---------- | ---------------------- | ------------------------ |
| **ReLU**     | [0, ∞)     | `max(0, x)`            | Hidden layers (default)  |
| **Leaky ReLU** | (-∞, ∞)  | `x if x>0 else 0.01x` | Avoids dying ReLU        |
| **Sigmoid**  | (0, 1)     | `1/(1+e^-x)`           | Binary classification output |
| **Softmax**  | (0, 1) sum=1 | `e^xi / Σe^xj`      | Multi-class output       |
| **Tanh**     | (-1, 1)    | `(e^x-e^-x)/(e^x+e^-x)` | Sometimes hidden layers |
| **Linear**   | (-∞, ∞)   | `x`                    | Regression output        |

## Building ANNs with Keras

### Example 1: Binary Classification

```python
import tensorflow as tf
from sklearn.datasets import make_classification
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler
from sklearn.metrics import classification_report
import numpy as np

# ── Data ──────────────────────────────────────────────────────────────────────
X, y = make_classification(n_samples=2000, n_features=20,
                            n_informative=10, random_state=42)
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2)
scaler = StandardScaler()
X_train = scaler.fit_transform(X_train)
X_test  = scaler.transform(X_test)

# ── Model ─────────────────────────────────────────────────────────────────────
model = tf.keras.Sequential([
    tf.keras.layers.Input(shape=(20,)),
    tf.keras.layers.Dense(128, activation='relu'),
    tf.keras.layers.BatchNormalization(),
    tf.keras.layers.Dropout(0.3),
    tf.keras.layers.Dense(64, activation='relu'),
    tf.keras.layers.BatchNormalization(),
    tf.keras.layers.Dropout(0.3),
    tf.keras.layers.Dense(32, activation='relu'),
    tf.keras.layers.Dense(1, activation='sigmoid')
])

model.compile(
    optimizer=tf.keras.optimizers.Adam(0.001),
    loss='binary_crossentropy',
    metrics=['accuracy', tf.keras.metrics.AUC(name='auc')]
)

model.summary()

# ── Train ─────────────────────────────────────────────────────────────────────
callbacks = [
    tf.keras.callbacks.EarlyStopping(patience=10, restore_best_weights=True),
    tf.keras.callbacks.ReduceLROnPlateau(patience=5, factor=0.5)
]

history = model.fit(X_train, y_train,
                    validation_split=0.2,
                    epochs=100,
                    batch_size=32,
                    callbacks=callbacks,
                    verbose=1)

# ── Evaluate ──────────────────────────────────────────────────────────────────
y_pred_prob = model.predict(X_test)
y_pred = (y_pred_prob > 0.5).astype(int)
print(classification_report(y_test, y_pred))
```

### Example 2: Multi-Class Classification (Iris)

```python
import tensorflow as tf
from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler
import numpy as np

# ── Data ──────────────────────────────────────────────────────────────────────
iris = load_iris()
X, y = iris.data, iris.target
y_cat = tf.keras.utils.to_categorical(y, num_classes=3)

X_train, X_test, y_train, y_test = train_test_split(X, y_cat, test_size=0.2, random_state=42)
scaler = StandardScaler()
X_train = scaler.fit_transform(X_train)
X_test  = scaler.transform(X_test)

# ── Model ─────────────────────────────────────────────────────────────────────
model = tf.keras.Sequential([
    tf.keras.layers.Dense(64, activation='relu', input_shape=(4,)),
    tf.keras.layers.Dense(32, activation='relu'),
    tf.keras.layers.Dense(3, activation='softmax')    # 3 classes
])

model.compile(
    optimizer='adam',
    loss='categorical_crossentropy',
    metrics=['accuracy']
)

history = model.fit(X_train, y_train,
                    validation_split=0.2,
                    epochs=100,
                    batch_size=16,
                    verbose=0)

loss, accuracy = model.evaluate(X_test, y_test, verbose=0)
print(f"Test Accuracy: {accuracy:.4f}")
```

### Example 3: Regression (House Prices)

```python
import tensorflow as tf
from sklearn.datasets import fetch_california_housing
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler

# ── Data ──────────────────────────────────────────────────────────────────────
housing = fetch_california_housing()
X, y = housing.data, housing.target
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2)
scaler = StandardScaler()
X_train = scaler.fit_transform(X_train)
X_test  = scaler.transform(X_test)

# ── Model ─────────────────────────────────────────────────────────────────────
model = tf.keras.Sequential([
    tf.keras.layers.Dense(256, activation='relu', input_shape=(8,)),
    tf.keras.layers.Dropout(0.2),
    tf.keras.layers.Dense(128, activation='relu'),
    tf.keras.layers.Dropout(0.2),
    tf.keras.layers.Dense(64, activation='relu'),
    tf.keras.layers.Dense(1)   # No activation for regression
])

model.compile(optimizer='adam', loss='mse', metrics=['mae'])

history = model.fit(X_train, y_train,
                    validation_split=0.2,
                    epochs=100,
                    batch_size=64,
                    callbacks=[tf.keras.callbacks.EarlyStopping(patience=10)],
                    verbose=0)

mse, mae = model.evaluate(X_test, y_test, verbose=0)
print(f"Test MAE: {mae:.4f}")
```

## Batch Normalization

Batch Normalization normalizes layer inputs for each mini-batch, which:
- Speeds up training
- Allows higher learning rates
- Acts as regularization

```python
# Place AFTER Dense, BEFORE activation (or after activation)
model = tf.keras.Sequential([
    tf.keras.layers.Dense(128),
    tf.keras.layers.BatchNormalization(),
    tf.keras.layers.Activation('relu'),
    tf.keras.layers.Dense(64),
    tf.keras.layers.BatchNormalization(),
    tf.keras.layers.Activation('relu'),
    tf.keras.layers.Dense(1, activation='sigmoid')
])
```

## Callbacks in Keras

| Callback               | Purpose                                          |
| ---------------------- | ------------------------------------------------ |
| `EarlyStopping`        | Stop training when val_loss stops improving      |
| `ModelCheckpoint`      | Save the best model during training              |
| `ReduceLROnPlateau`    | Reduce learning rate when plateaued             |
| `TensorBoard`          | Visualize training metrics in browser            |
| `LearningRateScheduler`| Custom learning rate schedule                   |

```python
callbacks = [
    tf.keras.callbacks.EarlyStopping(
        monitor='val_loss', patience=10, restore_best_weights=True
    ),
    tf.keras.callbacks.ModelCheckpoint(
        filepath='best_model.keras', save_best_only=True
    ),
    tf.keras.callbacks.ReduceLROnPlateau(
        monitor='val_loss', patience=5, factor=0.5, min_lr=1e-6
    )
]
```

# Save the full model

loaded_model = tf.keras.models.load_model('my_model.keras')
predictions = loaded_model.predict(X_test)

# Save only weights
model.save_weights('weights_only.h5')

# Load weights into a matching architecture
model.load_weights('weights_only.h5')
