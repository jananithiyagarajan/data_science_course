# Recurrent Neural Networks (RNN & LSTM)

## What is an RNN?

A **Recurrent Neural Network (RNN)** is a neural network designed for **sequential data** — data where the order matters.

Unlike ANNs and CNNs that process inputs independently, RNNs maintain a **hidden state** that carries information from previous time steps.

### What is Sequential Data?
- **Time series**: stock prices, temperature, sensor readings
- **Text**: words in a sentence carry meaning based on order
- **Audio**: sound waveforms over time
- **Video**: frames in sequence

```
Standard ANN:  x₁ → model → y₁   (independent)
               x₂ → model → y₂

RNN:           x₁ → [model + h₀] → y₁, h₁
               x₂ → [model + h₁] → y₂, h₂   ← uses previous hidden state
               x₃ → [model + h₂] → y₃, h₃
```

---

## The Vanishing Gradient Problem

Basic RNNs struggle to learn **long-term dependencies** — information from early time steps "vanishes" during backpropagation through time.

```
"The cat that ate the fish was ___"
     ↑                          ↑
  (important)              (needs to know
                           "cat" → singular)
```

In a long sequence, the gradient of "cat" becomes near-zero by the time it reaches the output → the model can't learn the connection.

**Solution:** LSTM (Long Short-Term Memory) and GRU (Gated Recurrent Unit)

---

## LSTM — Long Short-Term Memory

LSTM introduces a **cell state** (conveyor belt) that carries information across many time steps, controlled by **gates**.

### LSTM Gates

| Gate         | Purpose                                             |
| ------------ | --------------------------------------------------- |
| **Forget Gate** | Decides what to throw away from cell state       |
| **Input Gate**  | Decides what new information to add              |
| **Output Gate** | Decides what to output based on cell state       |

```
Cell State (long-term memory):   ──────────────────────────────→
                                   ↗ forget ↗ input ↗ output
Hidden State (short-term memory): ────────────────────────────→
```

## Building RNNs with Keras

### Example 1: Text Sentiment Classification (LSTM)

```python
import tensorflow as tf
from tensorflow import keras
import numpy as np

# ── Load IMDB Dataset ─────────────────────────────────────────────────────────
# 25,000 movie reviews labelled positive/negative
max_features = 10000   # vocabulary size (top 10k words)
maxlen = 200           # max review length (truncate/pad to 200 words)

(X_train, y_train), (X_test, y_test) = keras.datasets.imdb.load_data(
    num_words=max_features
)

# Pad sequences to equal length
X_train = keras.preprocessing.sequence.pad_sequences(X_train, maxlen=maxlen)
X_test  = keras.preprocessing.sequence.pad_sequences(X_test, maxlen=maxlen)

print(f"Train: {X_train.shape}  |  Test: {X_test.shape}")

# ── Build LSTM Model ──────────────────────────────────────────────────────────
model = keras.Sequential([
    keras.layers.Embedding(max_features, 128, input_length=maxlen),
    keras.layers.LSTM(64, return_sequences=True, dropout=0.2, recurrent_dropout=0.2),
    keras.layers.LSTM(32, dropout=0.2),
    keras.layers.Dense(1, activation='sigmoid')
])

model.compile(
    optimizer='adam',
    loss='binary_crossentropy',
    metrics=['accuracy']
)

model.summary()

# ── Train ─────────────────────────────────────────────────────────────────────
history = model.fit(
    X_train, y_train,
    validation_split=0.2,
    epochs=5,
    batch_size=64,
    verbose=1
)

# ── Evaluate ──────────────────────────────────────────────────────────────────
loss, acc = model.evaluate(X_test, y_test, verbose=0)
print(f"\nTest Accuracy: {acc:.4f}  ({acc*100:.2f}%)")
```

### Example 2: Time Series Forecasting (LSTM)

```python
import numpy as np
import tensorflow as tf
import matplotlib.pyplot as plt

# ── Generate a Sine Wave Time Series ─────────────────────────────────────────
t = np.linspace(0, 4*np.pi, 1000)
data = np.sin(t) + 0.1 * np.random.randn(1000)   # sine + noise

# ── Create Sequences ──────────────────────────────────────────────────────────
def create_sequences(data, seq_len=30):
    X, y = [], []
    for i in range(len(data) - seq_len):
        X.append(data[i:i + seq_len])
        y.append(data[i + seq_len])
    return np.array(X), np.array(y)

seq_len = 30
X, y = create_sequences(data, seq_len)
X = X.reshape((X.shape[0], X.shape[1], 1))   # (n_samples, timesteps, features)

# ── Train/Test Split ──────────────────────────────────────────────────────────
split = int(0.8 * len(X))
X_train, X_test = X[:split], X[split:]
y_train, y_test = y[:split], y[split:]

# ── Build LSTM ────────────────────────────────────────────────────────────────
model = tf.keras.Sequential([
    tf.keras.layers.LSTM(64, return_sequences=True, input_shape=(seq_len, 1)),
    tf.keras.layers.LSTM(32),
    tf.keras.layers.Dense(16, activation='relu'),
    tf.keras.layers.Dense(1)
])

model.compile(optimizer='adam', loss='mse')
model.fit(X_train, y_train, epochs=20, batch_size=32,
          validation_split=0.1, verbose=0)

# ── Predict & Plot ────────────────────────────────────────────────────────────
y_pred = model.predict(X_test)

plt.figure(figsize=(14, 5))
plt.plot(y_test, label='Actual', alpha=0.7)
plt.plot(y_pred, label='Predicted', alpha=0.7)
plt.title('LSTM Time Series Forecasting — Sine Wave')
plt.xlabel('Time Step')
plt.ylabel('Value')
plt.legend()
plt.show()

mse = np.mean((y_test - y_pred.flatten())**2)
print(f"Test MSE: {mse:.6f}")
```

## GRU — Gated Recurrent Unit

GRU is a simplified version of LSTM with **fewer parameters** and often similar performance.

```python
# Replace LSTM with GRU
model = tf.keras.Sequential([
    tf.keras.layers.Embedding(max_features, 128, input_length=maxlen),
    tf.keras.layers.GRU(64, dropout=0.2, return_sequences=True),
    tf.keras.layers.GRU(32, dropout=0.2),
    tf.keras.layers.Dense(1, activation='sigmoid')
])

# GRU trains faster than LSTM, usually comparable accuracy
```

| Feature   | RNN         | LSTM            | GRU              |
| --------- | ----------- | --------------- | ---------------- |
| Gates     | None        | 3 (forget, input, output) | 2 (reset, update) |
| Parameters| Fewest      | Most            | Moderate         |
| Long-term | Poor        | Excellent        | Good             |
| Speed     | Fastest     | Slowest          | Medium           |

## Bidirectional RNNs

A **Bidirectional LSTM** processes the sequence both forward and backward, giving the model context from both past AND future.

```python
model = tf.keras.Sequential([
    tf.keras.layers.Embedding(max_features, 128),
    tf.keras.layers.Bidirectional(
        tf.keras.layers.LSTM(64, return_sequences=True, dropout=0.2)
    ),
    tf.keras.layers.Bidirectional(
        tf.keras.layers.LSTM(32, dropout=0.2)
    ),
    tf.keras.layers.Dense(1, activation='sigmoid')
])

# Bidirectional: reads "I love deep learning" as:
# Forward:  I → love → deep → learning
# Backward: learning → deep → love → I
# Combined output captures full context
```

## Text Generation with LSTM

```python
import tensorflow as tf
import numpy as np

# ── Prepare Text Data ─────────────────────────────────────────────────────────
text = open('my_text.txt', 'r').read().lower()
chars = sorted(set(text))

char_to_idx = {c: i for i, c in enumerate(chars)}
idx_to_char = {i: c for c, i in char_to_idx.items()}

# ── Create Sequences ──────────────────────────────────────────────────────────
seq_length = 40
step = 3
sequences, next_chars = [], []

for i in range(0, len(text) - seq_length, step):
    sequences.append(text[i: i + seq_length])
    next_chars.append(text[i + seq_length])

X = np.zeros((len(sequences), seq_length, len(chars)), dtype=bool)
y = np.zeros((len(sequences), len(chars)), dtype=bool)

for i, seq in enumerate(sequences):
    for t, char in enumerate(seq):
        X[i, t, char_to_idx[char]] = 1
    y[i, char_to_idx[next_chars[i]]] = 1

# ── Build LSTM Text Generator ─────────────────────────────────────────────────
model = tf.keras.Sequential([
    tf.keras.layers.LSTM(128, input_shape=(seq_length, len(chars))),
    tf.keras.layers.Dense(len(chars), activation='softmax')
])

model.compile(optimizer='adam', loss='categorical_crossentropy')
model.fit(X, y, batch_size=128, epochs=20)

# ── Generate Text ─────────────────────────────────────────────────────────────
def generate_text(model, seed, length=200, temperature=1.0):
    generated = seed
    for _ in range(length):
        x = np.zeros((1, seq_length, len(chars)))
        for t, char in enumerate(seed[-seq_length:]):
            x[0, t, char_to_idx[char]] = 1
        preds = model.predict(x, verbose=0)[0]
        # Sample with temperature
        preds = np.log(preds + 1e-10) / temperature
        preds = np.exp(preds) / np.sum(np.exp(preds))
        next_char = idx_to_char[np.random.choice(len(chars), p=preds)]
        generated += next_char
        seed = seed[1:] + next_char
    return generated

print(generate_text(model, "the quick brown ", temperature=0.7))
```
