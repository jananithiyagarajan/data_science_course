# Window Functions in SQL

## What are Window Functions?

**Window Functions** perform calculations across a set of rows that are related to the current row — without collapsing the rows like GROUP BY does.

> Key difference: `GROUP BY` returns one row per group. **Window functions** return one row per original row, while also computing across a window of related rows.

---

## Syntax

```sql
function_name() OVER (
    [PARTITION BY column1, column2, ...]
    [ORDER BY column3 [ASC|DESC]]
    [ROWS/RANGE frame_specification]
)
```

| Clause         | Purpose                                        |
| -------------- | ---------------------------------------------- |
| `PARTITION BY` | Divides data into partitions (like GROUP BY)   |
| `ORDER BY`     | Defines the order within each partition        |
| `ROWS/RANGE`   | Defines the frame (subset) of rows to consider |

## 1. Ranking Functions

### `ROW_NUMBER()` — Unique sequential number per row

```sql
SELECT
    salesperson,
    amount,
    ROW_NUMBER() OVER (ORDER BY amount DESC) AS row_num
FROM sales;
```

### `RANK()` — Same rank for ties, gaps after ties

```sql
SELECT
    salesperson,
    amount,
    RANK() OVER (ORDER BY amount DESC) AS rank_pos
FROM sales;
-- If two rows tie for rank 1, next rank is 3 (not 2)
```

### `DENSE_RANK()` — Same rank for ties, NO gaps

```sql
SELECT
    salesperson,
    amount,
    DENSE_RANK() OVER (ORDER BY amount DESC) AS dense_rank
FROM sales;
-- If two rows tie for rank 1, next rank is 2
```

### `ROW_NUMBER` vs `RANK` vs `DENSE_RANK`

| Amount | ROW_NUMBER | RANK | DENSE_RANK |
| ------ | ---------- | ---- | ---------- |
| 60000  | 1          | 1    | 1          |
| 58000  | 2          | 2    | 2          |
| 55000  | 3          | 3    | 3          |
| 55000  | 4          | 3    | 3          |
| 25000  | 5          | 5    | 4          |

### `NTILE(n)` — Divide into n buckets

```sql
-- Divide salespeople into 4 performance quartiles
SELECT salesperson, amount,
       NTILE(4) OVER (ORDER BY amount DESC) AS quartile
FROM sales;
```

### `PERCENT_RANK()` — Percentile rank (0 to 1)

```sql
SELECT salesperson, amount,
       ROUND(PERCENT_RANK() OVER (ORDER BY amount), 2) AS pct_rank
FROM sales;
```

## 2. `PARTITION BY` — Ranking Within Groups

### Rank within each region

```sql
SELECT
    salesperson,
    region,
    amount,
    RANK() OVER (PARTITION BY region ORDER BY amount DESC) AS region_rank
FROM sales;
```

### Top salesperson per region

```sql
SELECT * FROM (
    SELECT
        salesperson,
        region,
        amount,
        ROW_NUMBER() OVER (PARTITION BY region ORDER BY amount DESC) AS rn
    FROM sales
) ranked
WHERE rn = 1;
```

## 3. `LEAD()` and `LAG()` — Access Adjacent Rows

### `LAG()` — Look at the previous row

```sql
SELECT
    salesperson,
    sale_date,
    amount,
    LAG(amount) OVER (PARTITION BY salesperson ORDER BY sale_date) AS prev_sale,
    amount - LAG(amount) OVER (PARTITION BY salesperson ORDER BY sale_date) AS change
FROM sales;
```

### `LEAD()` — Look at the next row

```sql
SELECT
    salesperson,
    sale_date,
    amount,
    LEAD(amount) OVER (PARTITION BY salesperson ORDER BY sale_date) AS next_sale
FROM sales;
```

### Common use: Month-over-month change

```sql
SELECT
    region,
    amount,
    LAG(amount, 1, 0) OVER (PARTITION BY region ORDER BY sale_date) AS prev_amount,
    ROUND((amount - LAG(amount, 1) OVER (PARTITION BY region ORDER BY sale_date))
          / LAG(amount, 1) OVER (PARTITION BY region ORDER BY sale_date) * 100, 2) AS pct_change
FROM sales;
```

## 4. Aggregate Window Functions

Window functions can also run aggregates (SUM, AVG, etc.) without collapsing rows.

### Running Total

```sql
SELECT
    salesperson,
    sale_date,
    amount,
    SUM(amount) OVER (ORDER BY sale_date) AS running_total
FROM sales;
```

### Running Total Per Region

```sql
SELECT
    region,
    salesperson,
    sale_date,
    amount,
    SUM(amount) OVER (PARTITION BY region ORDER BY sale_date) AS region_running_total
FROM sales;
```

### Moving Average (3-row window)

```sql
SELECT
    salesperson,
    sale_date,
    amount,
    AVG(amount) OVER (
        PARTITION BY salesperson
        ORDER BY sale_date
        ROWS BETWEEN 2 PRECEDING AND CURRENT ROW
    ) AS moving_avg_3
FROM sales;
```

### Percentage of Total per Region

```sql
SELECT
    region,
    salesperson,
    amount,
    SUM(amount) OVER (PARTITION BY region) AS region_total,
    ROUND(amount * 100.0 / SUM(amount) OVER (PARTITION BY region), 2) AS pct_of_region
FROM sales;
```

---

## 5. `FIRST_VALUE()` and `LAST_VALUE()`

```sql
-- Show the best sale in each region alongside each row
SELECT
    region,
    salesperson,
    amount,
    FIRST_VALUE(amount) OVER (PARTITION BY region ORDER BY amount DESC) AS best_in_region,
    LAST_VALUE(amount) OVER (
        PARTITION BY region ORDER BY amount DESC
        ROWS BETWEEN UNBOUNDED PRECEDING AND UNBOUNDED FOLLOWING
    ) AS worst_in_region
FROM sales;
```
