# What is SQL?

SQL stands for Structured Query Language

SQL lets you access and manipulate databases

SQL became a standard of the American National Standards Institute (ANSI) in 1986, and of the International Organization for Standardization (ISO) in 1987

# What Can SQL do?

SQL can execute queries against a database

SQL can retrieve data from a database

SQL can insert records in a database

SQL can update records in a database

SQL can delete records from a database

SQL can create new databases

SQL can create new tables in a database

SQL can create stored procedures in a database

SQL can create views in a database

SQL can set permissions on tables, procedures, and views

## Understanding Databases, Tables, and Records

### Database
A **database** is an organized collection of structured data stored electronically.
Think of it as a folder that contains many tables.

### Table
A **table** is a collection of related data organized in rows and columns — like a spreadsheet.

### Record (Row)
A **record** is a single entry in a table — one row of data.

```
employees table:
+--------+----------+------------+--------+
| emp_id | emp_name | department | salary |
+--------+----------+------------+--------+
|    101 | Arun     | IT         |  60000 |  ← This is one RECORD
|    102 | Priya    | HR         |  45000 |
+--------+----------+------------+--------+
```

### Primary Key
- Uniquely identifies each record in a table
- Cannot be NULL or duplicate

### Foreign Key
- Links two tables together
- References the primary key of another table

## Basic SQL Syntax Rules

```sql
-- 1. SQL is NOT case-sensitive for keywords (but use UPPERCASE by convention)
SELECT * FROM employees;  -- ✅
select * from employees;  -- ✅ (works but not preferred)

-- 2. Statements end with a semicolon (;)
SELECT * FROM employees;

-- 3. Comments
-- Single-line comment
/* Multi-line
   comment */

-- 4. String values go in single quotes
SELECT * FROM employees WHERE city = 'Chennai';

-- 5. Column names with spaces use backticks (MySQL)
SELECT `emp name` FROM employees;
```

## Core SQL Commands Overview

| Command   | Category | Purpose                    |
| --------- | -------- | -------------------------- |
| `SELECT`  | DQL      | Retrieve data              |
| `INSERT`  | DML      | Add new rows               |
| `UPDATE`  | DML      | Modify existing rows       |
| `DELETE`  | DML      | Remove rows                |
| `CREATE`  | DDL      | Create database/table      |
| `ALTER`   | DDL      | Modify table structure     |
| `DROP`    | DDL      | Delete database/table      |

### Basic SELECT

```sql
-- Select all columns
SELECT * FROM employees;

-- Select specific columns
SELECT emp_name, salary FROM employees;

-- Filter rows
SELECT * FROM employees WHERE department = 'IT';

-- Sort results
SELECT * FROM employees ORDER BY salary DESC;

-- Limit results
SELECT * FROM employees LIMIT 5;
```

**Objective**: Design a complete relational database schema.

**Instructions**:
Design a database for a **school management system** with:
- `students`: student_id, name, age, class, city
- `teachers`: teacher_id, name, subject, experience_yrs
- `courses`: course_id, course_name, teacher_id (FK)
- `enrollments`: enrollment_id, student_id (FK), course_id (FK), grade

Tasks:
1. Create all 4 tables with appropriate constraints.
2. Insert sample data (5 students, 3 teachers, 4 courses, 10 enrollments).

   - All students enrolled in a specific course
   - Average grade per course
   - Teacher with the most students
4. Add an index on `students.name` for faster searching.
5. Drop the database when done.

**Expected SQL**:
```sql
CREATE INDEX idx_student_name ON students(name);

SELECT c.course_name, AVG(e.grade) AS avg_grade
FROM enrollments e
JOIN courses c ON e.course_id = c.course_id
GROUP BY c.course_name;
```
