# Aggregate Function in SQL

An aggregate function in SQL is a function that performs a calculation on multiple rows of a table and returns a single summarized value.

Aggregate functions are mainly used for data analysis, reporting, and summarization.

## Common Aggregate Functions

| Function  | Description           | Example Use    |
| --------- | --------------------- | -------------- |
| `COUNT()` | Counts number of rows | Total records  |
| `SUM()`   | Adds numeric values   | Total salary   |
| `AVG()`   | Calculates average    | Average marks  |
| `MIN()`   | Finds smallest value  | Lowest price   |
| `MAX()`   | Finds largest value   | Highest salary |

### Task 2: GROUP BY & HAVING (Medium)
**Objective**: Practice grouping and filtering with HAVING.

1. Show the total quantity sold per category.
2. Show the average price per category, sorted by average price DESC.
3. Find categories where total revenue > ₹20,000.
4. Find the category with the maximum number of orders.
5. Show only categories where the average quantity sold is more than 3.

**Expected SQL**:
```sql
SELECT category, SUM(quantity) AS total_qty
FROM orders
GROUP BY category
ORDER BY total_qty DESC;

SELECT category, AVG(price) AS avg_price
FROM orders
GROUP BY category
HAVING AVG(price) > 5000;
```

### Task 3: Advanced Aggregation Queries (Challenge)
**Objective**: Combine aggregation with filtering and sorting.

1. Find the month-wise order count from `order_date`.
2. Find the customer who placed the most orders.
3. For each category, find the product with the highest price.
4. Calculate the percentage of total revenue each category contributes.
5. Find orders where the revenue (quantity × price) is above the overall average revenue per order.

**Expected SQL**:
```sql
-- Month-wise orders
SELECT MONTH(order_date) AS month, COUNT(*) AS orders
FROM orders
GROUP BY MONTH(order_date)
ORDER BY month;

-- % contribution per category
SELECT category,
       SUM(quantity * price) AS revenue,
       ROUND(SUM(quantity * price) * 100.0 /
             (SELECT SUM(quantity * price) FROM orders), 2) AS pct
FROM orders
GROUP BY category;
```
